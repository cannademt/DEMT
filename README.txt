МІЙ МАГАЗИН — як користуватися
================================

Це НЕ копія happyshop.org.ua.
Це оригінальний шаблон вітрини, який ви заповнюєте своїми даними.

Що вже є
- вікове вікно 18+
- каталог, пошук, фільтри
- картки товарів, модальне вікно
- кошик (зберігається в браузері)
- форма замовлення

Як поставити СВОЇ дані
1. Відкрийте файл products.js
2. У блоці SHOP_CONFIG змініть:
   - name        — назва магазину
   - phone, telegram, instagram, email
   - delivery, city
3. У масиві PRODUCTS додайте / замініть товари:
   - title, price, short, desc, image, volume, badge, inStock
4. Фото краще покласти в папку images/ і писати шлях так:
   image: "images/product-1.jpg"

Як відкрити сайт
- Двічі клацніть index.html
- Або залийте всю папку myshop на хостинг (GitHub Pages, Netlify, свій домен)

Чого тут немає (і це нормально)
- Онлайн-оплата LiqPay / Fondy / Shopify Payments
- Кабінет адміна з бази даних
- Інтеграція Нової Пошти API
- Облік залишків на складі

Для бойового магазину краще взяти готову платформу:
- Хорошоп (зручно для України)
- Shopify
- WooCommerce (WordPress)
- Prom.ua / Rozetka як вітрина

Важливо
Не копіюйте чужі фото, назви брендів, описи ефектів і дизайн один-в-один.
Ставте тільки свої матеріали і перевіряйте, що асортимент законний у вашій країні.
